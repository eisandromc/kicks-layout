KICKS — cinco implementações da mesma loja

Abra cada versão para comparar a construção do mesmo e-commerce com técnicas diferentes de layout.

Versões disponíveis

Dados, imagens e JavaScript de negócio são compartilhados. A camada de apresentação muda em cada pasta.

01

CSS Clássico

Layout sem Flexbox e sem CSS Grid, usando float, inline-block, table e clearfix.

Abrir versão CSS Clássico

02

CSS Grid

Layout estruturado com CSS Grid para áreas, colunas e listas responsivas.

Abrir versão CSS Grid

03

CSS Flexbox

Layout baseado em Flexbox, flex-wrap, flex-basis e distribuição de espaço.

Abrir versão Flexbox

04

Bootstrap

Layout com os componentes do Bootstrap 5 (navbar, card, grid, accordion). Tema roxo. O style.css só customiza.

Abrir versão Bootstrap

05

Tailwind CSS

Layout 100% em utilitários do Tailwind na marcação. Tema verde. O style.css só customiza.

Abrir versão Tailwind

Recursos compartilhados

O catálogo fica em shared/data/produtos.js, as imagens em shared/images e a lógica em shared/js/app.js.
